# Evaluacion_3_ingenieriaSoftware

## pasos para instalar

- descargar el archivo Zip y descomprimir sus contenidos

- abrir XAMP Control panel y activar Apache y MySQL

- ir a administrar MySQL y en la pagina ir a la parte que dice Importar

- selecionar el archivo comprimido de la base de datos, hotelriosur_db

- si el paso anterior no funciona, crear una nueva base de datos con el mismo nombre y abre el archivo sql en un lector de codigo como MySQL workbench traspasando el codigo en la pestaña de sql en la base de datos

- después de eso, abres el CMD de tu sistema y ejecutas los siguientes codigos

  ``` pip install django ```
  
  ``` pip install pymysql ```
  
  ``` pip install mysqlclient```

  ``` pip install crispy-bootstrap5 ```
  
- con esto ya deberías tener todo lo necesarios para que el proyecto funcione.
